# Portfolio — Fabián Muñoz

Personal portfolio of a Site Reliability Engineer, live at https://fabianimv.github.io/portfolio/.

Plain HTML, CSS and JavaScript with no framework or build step, deployed to GitHub Pages. The optional terminal mode in `portfolio-next/` is a static Next.js export with three.js, and `lambda/` holds the AWS Lambda backend for the AI chat assistant.
